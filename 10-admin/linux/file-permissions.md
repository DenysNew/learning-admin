# Права доступа Linux — краткая справка

Строка `-rwxr-xr--` состоит из типа файла и трёх групп прав: владелец, группа, остальные. Первый символ: `-` — обычный файл, `d` — каталог, `l` — символическая ссылка.

| Право | Число | Файл | Каталог |
| --- | --- | --- | --- |
| `r` | 4 | Читать содержимое | Читать список имён |
| `w` | 2 | Изменять содержимое | Изменять записи каталога при наличии `x` |
| `x` | 1 | Выполнять программу | Проходить через каталог и обращаться к его элементам |

Сумма даёт числовую запись: `rwx = 7`, `r-x = 5`, `r-- = 4`. Пример `754` соответствует `rwxr-xr--`.

## Специальные биты

| Бит | Значение | Назначение |
| --- | --- | --- |
| SUID | `4000` | У исполняемого файла эффективный UID может стать UID владельца; действуют ограничения ОС и файловой системы |
| SGID | `2000` | У исполняемого файла — эффективная группа; у каталога — наследование группы новыми элементами |
| Sticky | `1000` | В общем каталоге ограничивает удаление/переименование владельцем файла, владельцем каталога или привилегированным процессом |

Вместо `x` отображаются `s` (SUID/SGID) или `t` (sticky). Заглавные `S`/`T` означают, что соответствующий `x` не установлен. Примеры: `4755` — SUID + `755`; `1777` — обычные права `/tmp` со sticky bit.

## Просмотр и изменение

```bash
ls -la
stat filename
chmod 755 filename
find / -type f -perm -4000 2>/dev/null
```

Наличие SUID само по себе не доказывает уязвимость. Важны владелец, возможность изменения файла и поведение программы. Системная программа `passwd` — пример предусмотренного применения этого механизма.
