# Roadmap: Admin + Pentest + System Thinking (12 недель)

Цель:  
Построить фундамент администрирования, безопасности и пентеста  
с системным мышлением и реальными артефактами в Git.

Принцип обучения:
- 70% — лабы руками
- 30% — чтение / видео / конспект
- Каждая неделя заканчивается результатом (артефактом) в Git-репо:
  - заметки
  - скриншоты
  - конфиги
  - схемы
  - чеклисты

---

## Неделя 0 — Домашняя лаборатория (Mini-Infra)

Цель:  
Собрать мини-инфраструктуру для администрирования и безопасности.

Сделать:
- Гипервизор: VirtualBox или VMware
- 3 VM:
  - Ubuntu Server LTS
  - Windows Server (Evaluation)
  - Windows 10/11 Client
- Сети:
  - NAT (интернет)
  - Host-Only или Internal Network
- Статические IP в Internal:
  - 10.10.10.10 — Ubuntu
  - 10.10.10.20 — Windows Server
  - 10.10.10.30 — Windows Client

Артефакт:
- `30-architecture/diagrams/network-lab.png` или `.md`
- Таблица IP / ролей
- README по инфраструктуре

Системное мышление:
- Какие компоненты?
- Где граница доверия (NAT vs Internal)?
- Какие сервисы будут доступны снаружи?

Фокус:
- ФС
- find / grep
- chmod / chown / umask
- пользователи / группы
- sudo

Лабы:
- 3 пользователя: admin / user / auditor
- sudo:
  - user может перезапускать только один сервис
- /srv/app/{configs,data,logs} с правами

Материал:
- Linux Foundation — Introduction to Linux (free)

Артефакт:
- `10-admin/linux/01-users-groups.md`
- Скрины ls -ld
- README с командами и пояснениями

Системное мышление:
- Доступ = владелец + группа + права
- sudo = доверенная граница
- Плохие права = векторы атак
