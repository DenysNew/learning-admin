# Zrzuty ekranu laboratorium

Ten katalog zawiera obrazy środowiska VirtualBox używane w [dokumentacji laboratorium](../10-admin/lab-virtualization/README.md). Pozostałe dowody znajdują się w katalogach `artifacts` obok opisów konkretnych ćwiczeń.

Nazwy plików opisują konfigurację lub wynik testu. Prywatne adresy IP i nazwy VM pozostają widoczne; haseł i kluczy prywatnych nie publikujemy.
