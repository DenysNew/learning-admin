# 40-toolbox — Инструменты и шпаргалки

Этот раздел — мой личный “toolbox”: здесь я собираю команды, чек-листы, шпаргалки и полезные приёмы, которые использую в администрировании и пентесте.

## 🎯 Цели раздела
В этом разделе я:
- собираю полезные команды и сниппеты;
- структурирую свои чек-листы и методологии;
- создаю быстрые шпаргалки вместо долгого гугления;
- сохраняю маленькие скрипты и полезные приёмы;
- делаю знания практичными и легко воспроизводимыми.

## Структура

40-toolbox/
├── README.md        # ← этот файл
├── linux/           # команды и заметки по Linux
├── windows/         # команды и заметки по Windows
├── networking/      # сетевые инструменты и шпаргалки
├── web/             # веб-инструменты (Burp, curl, ffuf и т.д.)
├── pentest/         # общие пентест-чеклисты и методологии
└── scripts/         # мои маленькие скрипты

*(Структура может меняться по мере обучения.)*

## Как я использую toolbox
Каждая заметка/шпаргалка должна:
- быть **короткой и практичной**;
- содержать **пример команды или сценария**;
- объяснять *зачем* это нужно, а не только *как*;
- иметь понятное название файла.

## Что здесь можно найти (примеры)
- Быстрые команды Nmap и их смысл  
- Полезные Linux one-liners  
- Шпаргалки по Git и PowerShell  
- Шаблоны команд для веб-разведки  
- Чек-листы перед/после пентеста  
- Маленькие скрипты автоматизации  

## Связь с остальными разделами
- **10-admin** → здесь лежат *шпаргалки* по администрированию.  
- **20-pentest** → здесь лежат *инструменты и чек-листы* для атакующего.  
- **30-architecture** → здесь могут быть шаблоны диаграмм и схем.
