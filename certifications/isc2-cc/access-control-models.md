# Access Control Models

## Описание темы

Контроль доступа (**Access Control**) — это механизм безопасности, который определяет:

- **кто может получить доступ к ресурсам**
- **какие действия он может выполнять**

Главная цель контроля доступа:

**Разрешить доступ только авторизованным пользователям.**

---

# Основные компоненты контроля доступа

Контроль доступа часто описывается моделью **AAA**.

| Английский термин | Русский смысл |
|---|---|
| Authentication | Проверка личности |
| Authorization | Назначение прав доступа |
| Accounting | Учёт действий пользователя |

Пример:

Authentication → пользователь вводит пароль  
Authorization → система определяет права доступа  
Accounting → система записывает действия пользователя в логи

---

# Модели контроля доступа

## RBAC — Role-Based Access Control

Контроль доступа на основе **ролей**.

Права доступа назначаются **ролям**, а не отдельным пользователям.

Пример:
Administrator → полный доступ
Manager → доступ к финансовым данным
Employee → ограниченный доступ


### Перевод ключевых слов

| English | Русский |
|---|---|
| role | роль |
| job function | рабочая функция |
| department | отдел |
| user role | роль пользователя |

### Экзаменационный паттерн

Если в вопросе встречаются слова:

- **role**
- **job function**
- **department**

Правильный ответ обычно **RBAC**.

---

## MAC — Mandatory Access Control

Обязательный контроль доступа.

Права доступа устанавливаются **центральной системой** и не могут изменяться пользователем.

Используются **security labels** (метки безопасности).

Пример классификации:
Employee A → создаёт платёж
Employee B → подтверждает платёж


### Ключевые слова

| English | Русский |
|---|---|
| separation of duties | разделение обязанностей |
| multiple users | несколько пользователей |
| critical process | критический процесс |

---

# Быстрое сравнение моделей

| Модель | Кто контролирует доступ | Основная идея |
|---|---|---|
| RBAC | Роли | доступ по роли |
| MAC | Система | уровни секретности |
| DAC | Владелец данных | владелец решает |
| ABAC | Политики | атрибуты |

---

# Экзаменационные паттерны

| Ключевые слова в вопросе | Скорее всего ответ |
|---|---|
| role / job function | RBAC |
| classification | MAC |
| security label | MAC |
| data owner | DAC |
| owner permissions | DAC |
| location | ABAC |
| device type | ABAC |

---

# Итог

Основные модели контроля доступа:

RBAC → доступ по роли  
MAC → доступ по уровню секретности  
DAC → доступ определяет владелец  
ABAC → доступ на основе атрибутов  

Важные принципы безопасности:

Least Privilege → минимальные права  
Separation of Duties → разделение обязанностей
